# Сугроб (Snowdrift)

Снег поверх рабочего стола macOS. Снежинки падают, ложатся сугробами на верхние
кромки окон и на низ экрана, осыпаются, слетают с краёв и реагируют на курсор.

Один файл на Swift, без зависимостей, без Xcode-проекта.

## Возможности

- **Снегопад** — снежинки трёх размеров («глубина»), покачивание и плавно
  меняющийся ветер.
- **Сугробы на окнах** — снег копится на верхней кромке каждого видимого окна
  (с учётом перекрытия другими окнами) и вдоль нижнего края экрана.
- **Осыпание** — слишком крутой склон сползает; с краёв окна снег срывается
  комками и летит вниз, где может лечь на окно ниже.
- **Курсор** — сгребает сугроб как лопата и разбрасывает снег в сторону
  движения; падающие снежинки рядом с курсором увлекаются за ним.
- **Окна** — если окно подвинуть или закрыть, снег с него стряхивается с
  учётом скорости окна. Если одно окно наезжает на сугроб другого, снег
  поднимается на кромку переднего окна.
- **Dock** (по желанию) — сугроб на Dock, если он расположен снизу.

Слой со снегом прозрачен для мыши: клики и перетаскивания проходят сквозь него.

## Требования

- macOS 14 или новее
- Xcode Command Line Tools (`xcode-select --install`) — нужен `swiftc`

## Сборка и запуск

```sh
sh build.sh
open Snowdrift.app
```

`build.sh` создаёт `Snowdrift.app` рядом с исходником и подписывает его
ad-hoc-подписью. Собранное приложение в репозиторий не входит.

Чтобы приложение стартовало при входе в систему, добавьте `Snowdrift.app` в
«Системные настройки → Основные → Объекты входа».

## Управление

У приложения нет окна и значка в Dock — только значок ❄️ в строке меню:

| Пункт меню | Действие |
| --- | --- |
| Снег идёт | Пауза / продолжить (на паузе слой скрывается) |
| Лёгкий снежок / Снегопад / Метель | Интенсивность, запоминается между запусками |
| Не засыпать содержимое окон | Окна становятся непроницаемыми: снег ложится на кромку или отскакивает от боковых краёв, но не летит поверх содержимого. Запоминается между запусками |
| Стряхнуть весь снег | Сбросить все сугробы — снег падает вниз |
| Снег на Dock | Запросить «Универсальный доступ» для сугроба на Dock |
| Выйти | Завершить приложение |

## Разрешения

Базовая работа **не требует никаких разрешений**: положение окон берётся из
`CGWindowListCopyWindowInfo` (только рамки, без содержимого и заголовков),
положение курсора — из `NSEvent.mouseLocation`.

«Универсальный доступ» нужен только для сугроба на Dock: через Accessibility
API читается прямоугольник Dock. Без него снег просто копится вдоль нижнего
края экрана. Ad-hoc-подпись меняется при каждой пересборке, поэтому после
`build.sh` доступ, возможно, придётся выдать заново.

## Как это устроено

Весь код — в `main.swift`.

**Координаты.** Симуляция считает в точках, начало — левый верхний угол
основного экрана, ось Y вниз. Так же отдаёт рамки окон `CGWindowList`, поэтому
пересчёт не нужен. Слой отрисовки переворачивается явным преобразованием.

**Частицы** (`Particle`). Два вида: снежинки (лёгкие, малая предельная скорость,
покачиваются) и комки (`debris` — снег, сбитый с сугроба: тяжёлые, падают
быстро). У каждой частицы есть масса; при приземлении она переходит в сугроб,
при срыве — обратно в частицы, так что снег не появляется из ниоткуда.
Ложиться умеют только ближние снежинки, дальние пролетают «за» окнами.

**Поверхности** (`Surface`). Верхняя кромка окна — массив высот столбиков
шириной 2 pt. Для каждого столбика хранится, виден ли он (не перекрыт ли окном
спереди). Раз в 50 мс список окон опрашивается заново; поверхность
привязана к номеру окна. Если окно сдвинулось, снег сбрасывается частицами
со скоростью окна. При изменении ширины снег остаётся на своём месте на
экране. Снег со столбика, который накрыло окно спереди, переносится на кромку
этого окна.

**Шаг физики** (`Sim.step`), каждый кадр:

1. рождаются новые снежинки;
2. курсор — круг радиуса `cursorR` — срезает столбики, в которые попал, и
   превращает срезанное в комки с импульсом от скорости курсора;
3. частицы двигаются (тяга к предельной скорости, ветер, вихрь от курсора) и
   проверяются на приземление;
4. сугробы осыпаются: перепад между соседними столбиками больше `slope`
   выравнивается; излишек на крайних столбиках срывается комками.

**Непроницаемые окна** (`Sim.solid`). В этом режиме на кромку ложатся все
снежинки, а не только ближние. Частица, оказавшаяся внутри рамки любого окна,
либо отскакивает (если влетела сбоку), либо исчезает (если упала на кромку,
где сугроб уже полон или его нет). Полноэкранные окна в этом режиме снега не
получают вовсе.

**Отрисовка.** Прозрачное окно без рамки на уровне строки меню, на всех
рабочих столах. Три `CAShapeLayer` для снежинок (разная прозрачность) и один
для сугробов; пути пересобираются каждый кадр по `CADisplayLink`.

## Настройка

Константы в начале `main.swift`:

| Константа | Значение | Смысл |
| --- | --- | --- |
| `colW` | 2 | Ширина столбика сугроба, pt |
| `maxPile` | 18 | Предельная высота сугроба, pt |
| `slope` | 1.4 | Допустимый перепад между столбиками (крутизна склона) |
| `cursorR` | 12 | Радиус «лопаты» курсора, pt |
| `maxParticles` | 6000 | Потолок числа частиц |

Интенсивности снегопада — массив `rates` в `AppDelegate` (снежинок в секунду
на 1000 pt ширины экрана).

## Ограничения

- Снег идёт только на основном экране.
- Сугроб на Dock — только при Dock снизу; его высота над Dock подобрана
  приблизительно (`d.minY - 5` в `refreshWindows`).
- Кромка окна считается прямой с отступом 8 pt под скруглённые углы.
- Полноэкранные окна сугробов не получают.
- В покое приложение занимает порядка 7–9 % одного ядра CPU.
