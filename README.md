# Сугроб (Snowdrift)

Осадки поверх рабочего стола: снег, дождь, песок и листья — по времени года
или на выбор. Они падают, ложатся кучами на верхние кромки окон и на низ
экрана, осыпаются, слетают с краёв и реагируют на курсор.

Написан на Rust, одна кодовая база для **macOS, Windows и Linux (X11)**.
Отрисовка идёт на GPU.

## Состояние по платформам

| Платформа | Графика | Состояние |
| --- | --- | --- |
| macOS 11+ | Metal | Работает, проверено запуском |
| Windows 10/11 | DirectX 12 | Компилируется, **на Windows ещё не запускалось** |
| Linux, X11 | Vulkan / OpenGL | Компилируется, **на Linux ещё не запускалось** |

Windows и Linux собраны и проверены компилятором на Mac, но вживую их никто не
видел: первый запуск на этих системах — это проверка. При старте приложение
пишет в stderr выбранный GPU и режим прозрачности — эта строка пригодится,
если что-то пойдёт не так.

## Возможности

- **Четыре вида осадков** с общей физикой и разными размерами и повадками:

  | | Размер (снежинка = 1) | Как падает | Как лежит |
  | --- | --- | --- | --- |
  | Снег (зима) | 1 | Медленно, покачиваясь | Сугробы |
  | Дождь (весна) | 0,6 | Быстрыми косыми штрихами, с брызгами | Растекается ровным слоем, стекает с краёв и высыхает |
  | Песок (лето) | 0,35 | Быстро, сильно сносится ветром | Барханы с крутым склоном |
  | Листья (осень) | 2,5 | Медленно, порхают и кружатся | Рыхлый пёстрый слой |

  По умолчанию вид выбирается по календарю (северное полушарие).
- **Глубина** — частицы трёх размеров, покачивание и плавно меняющийся ветер.
- **Сугробы на окнах** — снег копится на верхней кромке каждого видимого окна
  (с учётом перекрытия другими окнами) и вдоль нижнего края экрана.
- **Осыпание** — слишком крутой склон сползает; с краёв окна снег срывается
  комками и летит вниз, где может лечь на окно ниже.
- **Курсор** — сгребает сугроб как лопата и разбрасывает снег в сторону
  движения; падающие снежинки рядом с курсором увлекаются за ним.
- **Окна** — если окно подвинуть или закрыть, снег с него стряхивается с
  учётом скорости окна. Если одно окно наезжает на сугроб другого, снег
  поднимается на кромку переднего окна.
- **Dock / панель задач** — сугроб на них, если они расположены снизу.
- **Непроницаемые окна** (по желанию) — снег не идёт поверх содержимого окон.

Слой со снегом прозрачен для мыши: клики и перетаскивания проходят сквозь него.

## Сборка и запуск

Нужен [Rust](https://rustup.rs) (stable).

```sh
cargo run --release
```

Готовый файл — `target/release/snowdrift` (`snowdrift.exe` в Windows).

**macOS.** Чтобы получить приложение, которое запускается двойным щелчком:

```sh
sh scripts/bundle-macos.sh
open dist/Snowdrift.app
```

**Linux.** Нужны X11-сеанс (или XWayland), композитор и оконный менеджер с
поддержкой EWMH — это любой распространённый рабочий стол. Для значка в трее
нужна поддержка StatusNotifierItem (в GNOME — расширение AppIndicator).

Сборка под все три системы настроена в GitHub Actions
(`.github/workflows/build.yml`) и заработает, когда у репозитория появится
origin на GitHub.

## Управление

Окна у приложения нет — только значок-снежинка в трее (строке меню):

| Пункт меню | Действие |
| --- | --- |
| Включено | Пауза / продолжить (на паузе слой скрывается) |
| По времени года / Снег / Дождь / Песок / Листья | Что падает. При смене старые кучи осыпаются |
| Слабо / Умеренно / Сильно | Интенсивность |
| Не засыпать содержимое окон | Окна становятся непроницаемыми: снег ложится на кромку или отскакивает от боковых краёв, но не летит поверх содержимого |
| Стряхнуть всё | Сбросить все кучи — они падают вниз |
| Ложиться на Dock | Только macOS: запросить «Универсальный доступ», чтобы осадки ложились на Dock |
| Аппаратное ускорение (GPU) | Рисовать на видеокарте или программно, на процессоре. Ниже показан используемый адаптер. Пункт неактивен, если программной отрисовки в системе нет — так на macOS |
| Выйти | Завершить приложение |

Все настройки меню запоминаются между запусками в файле
`snowdrift/settings.conf` в папке настроек пользователя
(`~/Library/Application Support`, `%APPDATA%`, `~/.config`).

## Разрешения

Базовая работа **не требует никаких разрешений** ни на одной системе: читаются
только рамки окон и положение курсора, без содержимого и заголовков.

На macOS «Универсальный доступ» нужен только для сугроба на Dock. Без него
снег копится вдоль нижнего края экрана. Подпись приложения меняется при каждой
пересборке, поэтому после `bundle-macos.sh` доступ, возможно, придётся выдать
заново. В Windows и Linux панель задач видна без разрешений.

## Как это устроено

| Файл | Роль |
| --- | --- |
| `src/materials.rs` | Таблица материалов: размеры, полёт, куча, внешний вид |
| `src/sim.rs` | Физика, общая для всех материалов. Не зависит ни от ОС, ни от отрисовки; покрыта тестами |
| `src/render.rs`, `src/shader.wgsl` | Отрисовка на GPU через wgpu |
| `src/platform/` | Список окон, курсор, Dock / панель задач — по модулю на ОС |
| `src/tray.rs` | Значок и меню в трее |
| `src/settings.rs` | Настройки пользователя |
| `src/main.rs` | Окно-оверлей и цикл кадров |

**Координаты.** Симуляция считает в логических точках, начало — левый верхний
угол основного экрана, ось Y вниз. macOS отдаёт рамки окон в точках, Windows и
X11 — в физических пикселях; пересчёт делается в `main.rs` по константе
`platform::PHYSICAL`.

**Материалы.** Физика одна на всех; материал — это строка чисел в
`src/materials.rs`. Размер задан множителем `scale` относительно снежинки, от
него считаются радиус и масса. Остальные числа описывают полёт (предельная
скорость, снос ветром, покачивание, вращение), кучу (угол осыпания, предельная
высота, высыхание) и внешний вид (форма, цвета). Чтобы добавить новый вид
осадков, достаточно новой строки в этой таблице и пункта в `Kind`.

**Частицы.** Два вида: снежинки (лёгкие, покачиваются) и комки — снег, сбитый
с сугроба (тяжёлые, падают быстро). У каждой частицы есть масса; при
приземлении она переходит в сугроб, при срыве — обратно в частицы, так что
снег не появляется из ниоткуда. Ложиться умеют только ближние снежинки,
дальние пролетают «за» окнами.

**Поверхности.** Верхняя кромка окна — массив высот столбиков шириной 2 pt.
Для каждого столбика хранится, виден ли он (не перекрыт ли окном спереди).
Раз в 50 мс список окон опрашивается заново; поверхность привязана к номеру
окна. Если окно сдвинулось, снег сбрасывается частицами со скоростью окна.
При изменении ширины снег остаётся на своём месте на экране. Снег со столбика,
который накрыло окно спереди, переносится на кромку этого окна.

**Шаг физики** (`Sim::step`), каждый кадр:

1. рождаются новые снежинки;
2. курсор — круг радиуса `CURSOR_R` — срезает столбики, в которые попал, и
   превращает срезанное в комки с импульсом от скорости курсора;
3. частицы двигаются (тяга к предельной скорости, ветер, вихрь от курсора) и
   проверяются на приземление;
4. сугробы осыпаются: перепад между соседними столбиками больше `SLOPE`
   выравнивается; излишек на крайних столбиках срывается комками.

**Непроницаемые окна** (`Sim::solid`). В этом режиме на кромку ложатся все
снежинки, а не только ближние. Частица, оказавшаяся внутри рамки любого окна,
либо отскакивает (если влетела сбоку), либо исчезает (если упала на кромку,
где сугроб уже полон или его нет).

**Отрисовка.** Прозрачное окно без рамки поверх всех окон. Частицы рисуются
одним вызовом: инстансированные квадраты, форма (крупинка, штрих дождя, лист)
считается и сглаживается во фрагментном шейдере. Сугробы — треугольники с мягкой тенью над кромкой. Кадры идут по
вертикальной синхронизации. Выбирается энергоэффективный GPU (встроенная
графика); если GPU нет, wgpu использует программный адаптер.

**Прозрачность в Windows.** Прозрачное окно с GPU-отрисовкой там возможно
только через DirectX 12 и DirectComposition, поэтому этот бэкенд пробуется
первым.

## Настройка

Свойства каждого вида осадков — в `src/materials.rs`: каждое поле структуры
`Material` подписано. Самые заметные: `scale` (размер), `rate` (сколько частиц),
`fall_base` (скорость падения), `slope` и `max_pile` (форма и высота кучи).

Общие константы в начале `src/sim.rs`:

| Константа | Значение | Смысл |
| --- | --- | --- |
| `COL_W` | 2 | Ширина столбика кучи, pt |
| `CURSOR_R` | 12 | Радиус «лопаты» курсора, pt |
| `MAX_PARTICLES` | 6000 | Потолок числа частиц |

Интенсивности — массив `RATES` в `src/settings.rs` (снежинок в секунду на
1000 pt ширины экрана; для других материалов умножается на `rate`).

## Тесты

```sh
cargo test
```

Тесты проверяют физику: накопление каждого материала, стряхивание при сдвиге
окна, перенос на переднее окно с сохранением массы, непроницаемые окна, срез
курсором, растекание и высыхание воды, смену материала, выбор по календарю.

## Ограничения

- Снег идёт только на основном экране.
- Сугроб на Dock и панели задач — только если они расположены снизу; на macOS
  высота сугроба над Dock подобрана приблизительно (`DOCK_LIFT`).
- Кромка окна считается прямой с отступом 8 pt под скруглённые углы.
- Полноэкранные и развёрнутые на весь экран окна сугробов не получают.
- **Wayland.** Протокол не позволяет узнать положение чужих окон, поэтому в
  сеансе Wayland приложение работает через XWayland и видит только окна
  X11-приложений. Полноценно — только в сеансе X11.
- На macOS приложение занимает порядка 10 % одного ядра CPU.
